# Icons

`pi-tombstone.svg` is the app icon (`icon:` in `dev-services.yaml`, shown at 32 px in the Hammerspoon panel). The others are kept as alternates.

| File | Idea | Why not the app icon |
|---|---|---|
| `pi-tombstone.svg` | Pi closed by the square that ends a proof: the name itself | In use: carries both halves of the name |
| `pi-disc.svg` | Pi on a gold disc | Drops Q.E.D., half of the name |
| `profile-card.svg` | A profile card with a portrait and the page's language donut | Describes the page, but it is too fine at panel size and doesn't say whose it is |

Checked against the panel's backgrounds (`#24282a`, `#2f3a40`) and white.
